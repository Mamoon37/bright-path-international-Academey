Featured course: Web Development Foundations

This 12-week course takes complete beginners from a blank file to a published, responsive website. Students learn semantic HTML, CSS layout, forms and the basics of JavaScript, then finish by building a personal portfolio site.

What you will learn

Page structure, typography, colour, flexbox, accessibility and publishing with GitHub Pages. Each week has a live lab session and a small graded task.

Who it is for

School leavers, university students and career changers. No previous coding experience is needed. Ready to start? Go to the registration form or return to the home page.

Announcement

The new batch starts on 3 November 2026. Register by 25 October for 10% off the course fee.

Useful tip

Bring your own laptop if you can. Lab computers are available for students who do not have one.
